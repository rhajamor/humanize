# humanize

LLM prose has a fingerprint. Readers see it and stop trusting the rest. This skill writes so that fingerprint never lands, and sweeps existing drafts until it is gone.

Word swaps do not do it. Commitment and specifics do. Uneven rhythm too, as long as the short sentences are not stacked into a poem.

## Install

```bash
npx skills add rhajamor/humanize
```

Global, every project on this machine:

```bash
npx skills add rhajamor/humanize -g
```

That is also how the skill shows up on [skills.sh](https://skills.sh). There is no submit form. Installs are the listing.

## Use

Ask an agent to humanize, de-AI, or naturalize a draft. Or install it as the default for anything a person will read: email, Slack, docs, a post, a report.

It will not invent a number or a name to sound human. If the source has no specific, the rewrite stays plainly general, or it asks.

It will not mention these rules in the output. It just writes inside them.

A single flagged word is not a verdict. Clusters are. Keep a distinctive voice and any real detail. Mixed feelings stay. Do not install a new regularity in place of the old one.
